Configure GH_AW_AGENT_TOKEN or assign-to-agent.github-token with a valid user token: a fine-grained PAT with metadata: read and actions, contents, issues, and pull requests: write, or a classic PAT with repo scope. Check token expiry, repository access, and organization approval/SSO. GitHub App installation tokens, including GITHUB_TOKEN, cannot assign Copilot. See https://github.github.com/gh-aw/reference/copilot-cloud-agent/#authentication
